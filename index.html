A problem I solved

Keeping the Lock Screen score correct

In KickFlow, Live Activity updates ran in independent tasks, so two updates could finish in the wrong order and the Lock Screen showed an old score. A fast follow toggle could also lose the push token, and pushes stopped with no error.

The fix: a chain of tasks for each match, so start, update, end and token registration run in order, and a freshness check that compares match phase, elapsed time and stoppage time as an ordered tuple instead of one packed number.
